💡 How to use

  1. Manage and add your owned filaments in the left column.
  2. Choose two colors and a mixing curve in the center column, then review the resulting ratios.
  3. [Optional] Add the resulting mix as a new Owned Filament using the "➕" button.
  4. Select a model in the right column and open the download page.
  5. Download the 3MF file that matches your selected blending ratio.

Note:

  1. Auto curve selection and curve itself do not guarantee optimal final results. for better results, consult @sheepycloud's Color_Result_Chart, which is in Documentation section of the FlexChroma Blend Filament Index page.
  2. Data of filaments are obtained from SpoolmanDB.
  3. KM (Kubelka-Munk theory) in curve selection is generated by spectral.js
  4. Thanks @sheepycloud for creating such a useful tool!
