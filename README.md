# FlexChroma-Blend-Filament--Color-Mixer

go to site: [FlexChroma Blend Filament - Color Mixer](https://github.com/adonishi/FlexChroma-Blend-Filament--Color-Mixer)

### Background
color mixing/blending filament for 3D print is a technique to mix multiple color filament to make new filament (and used it again in 3D printer).
There are some color mixing filament out there. among them, I think, [FlexChroma Blend Filament](https://makerworld.com/en/models/2579268-flexchroma-blend-filament-index) is one step better, because of structure of colors in filament and existance of mesured acurate color chart.

but there is a problem, it is only support specified filament (namely Bambulab's basic filaments).

this Color Mixer help to use any filament for FlexChroma.

### usage
* Manage and add your owned filaments in the left column.
* Choose two colors and a mixing curve in the center column, then review the resulting ratios.
* [Optional] Add the resulting mix as a new Owned Filament.
* Select a model in the right column and open the download page.
* Download the 3MF file that matches your selected blending ratio.

### note
* Auto curve selection and curve itself do not guarantee optimal final results. for better results, consult @sheepycloud's Color_Result_Chart, which is in Documentation section of the [FlexChroma Blend Filament Index](https://makerworld.com/en/models/2579268-flexchroma-blend-filament-index) page.
* Data of filaments are obtained from [SpoolmanDB](https://github.com/Donkie/SpoolmanDB).
* KM (Kubelka-Munk theory) in curve selection is generated by [spectral.js](https://github.com/rvanwijnen/spectral.js/)
* Thanks [@sheepycloud](https://makerworld.com/en/@sheepycloud) for creating such a useful tool!
